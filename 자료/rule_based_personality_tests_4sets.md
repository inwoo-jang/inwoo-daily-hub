# 공통 구현 규칙

## 기본 계산법

각 선택지는 특정 결과에 점수를 부여합니다.

```ts
scores[결과ID] += 부여점수
```

모든 질문에 답한 후 가장 높은 점수를 받은 결과를 최종 결과로 표시합니다.

## 권장 점수 구조

- 대표 결과: `+3`
- 보조 결과: `+1`
- 선택지 하나당 최대 2개 결과에 점수 부여
- 7문항 기준 최대점은 대략 12~18점

```json
{
  "scores": {
    "primary_result": 3,
    "secondary_result": 1
  }
}
```

## 동점 처리

1. 마지막 문항의 선택지에서 더 높은 점수를 받은 결과
2. 그래도 동점이면 `tieBreakerPriority`가 높은 결과
3. 결과가 매번 바뀌는 재미를 주고 싶다면 동점 결과 중 랜덤 선택

## 결과 화면 권장 구성

- 결과명
- 한 줄 별명
- 4~6줄 성격 설명
- 핵심 키워드 3개
- 강점 3개
- 주의할 점 2개
- 잘 맞는 결과
- 결과 공유 문구
- 다른 테스트로 이동하는 CTA

## 결과 계산 예시

```ts
function calculateResult(
  questions: TestQuestion[],
  selectedOptionIds: Record<string, string>,
  tieBreakerPriority: string[]
) {
  const scores: Record<string, number> = {};

  for (const question of questions) {
    const selectedOptionId = selectedOptionIds[question.id];
    const selected = question.options.find(
      (option) => option.id === selectedOptionId
    );

    if (!selected) continue;

    for (const [resultId, point] of Object.entries(selected.scores)) {
      scores[resultId] = (scores[resultId] ?? 0) + point;
    }
  }

  const priorityIndex = new Map(
    tieBreakerPriority.map((resultId, index) => [resultId, index])
  );

  return Object.entries(scores).sort((a, b) => {
    if (b[1] !== a[1]) return b[1] - a[1];

    return (
      (priorityIndex.get(a[0]) ?? Number.MAX_SAFE_INTEGER) -
      (priorityIndex.get(b[0]) ?? Number.MAX_SAFE_INTEGER)
    );
  })[0]?.[0];
}
```
